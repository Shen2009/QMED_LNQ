# QMED_LNQ

This repository is now a frontend-only Expo project skeleton.

## Structure

```text
Q-Med/
└── frontend/
    ├── App.tsx
    ├── src/
    │   ├── core/
    │   ├── features/
    │   └── shared/
    └── package.json
```

## Run

```bash
cd frontend
npm install
npx expo start
```

## Current Scope

- App shell
- Main tabs
- Shared UI components
- Onboarding and language selection
- Placeholder screens for Home, Measure, History, Q-Bot, and Settings
